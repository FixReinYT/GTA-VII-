# Lake City — Четыре минуты

Игровой прототип для Windows x64, Godot 4.6.3. Вера забирает Рэя у прачечной, уходит от патруля под эстакадой и возвращается в гараж отца. Золотой столб отмечает текущую цель.

[Скачать последнюю сборку](https://github.com/FixReinYT/GTA-VII-/releases/latest/download/LakeCity.exe)

WASD или стрелки — газ, задний ход и поворот. Пробел — тормоз. R — начать заново. Для посадки и завершения поездки остановитесь у метки.

Для локального запуска откройте project.godot в Godot 4.6.3. Сборка Windows публикуется через GitHub Actions.

Город, машины и уличная мебель используют [KayKit City Builder Bits](https://github.com/KayKit-Game-Assets/KayKit-City-Builder-Bits-1.0), автор Kay Lousberg. Лицензия CC0 приложена в art/kaykit/LICENSE.txt.
